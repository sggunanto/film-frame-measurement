# The coding instrument

## Structure

One row per unit (frame). Unit-above-frame variables (anything needing duration: editing rhythm, sound,
off-frame space) are coded once on a designated frame of the sequence and copied across its frames —
record which, so the duplication is visible rather than looking like three independent observations.

Every variable needs five things, and a variable missing any of them will not survive a reliability
check: **name, scale type, ordered levels, a decision rule, and two anchor descriptions per level**.
Write the anchors operationally ("the largest figure's height exceeds two thirds of frame height"), not
by example ("as in the scene where..."), so they transfer to a corpus the author has not seen. Attach
real anchor images from a *training* set during coder training — never from the analysis set.

## Two rounds, not one pass

**Round 1 (descriptive)** — what is visible and audible: time of day, dominant motif, figure count,
viewpoint, figure-to-space scale, movement type, shot length, sound register, off-frame space. Chosen so
that a coder who does not know the hypotheses can complete them.

**Round 2 (interpretive)** — the construct itself: whether two codes are co-present, what carries the
tension, what affective work it does, and the mandatory alternative reading.

Finish round 1 for every unit before starting round 2. Code **one variable at a time across all units**
where practical: column-wise coding keeps level thresholds stable, row-wise coding drifts.

The split is what lets the second coder be given round 1 without being told what the study expects.

## Evidence rules

Two rules do most of the work in keeping interpretation accountable:

**Name the evidence inline.** Any code asserting that two codes are both present must carry, in the same
row, the concrete image or sound element standing for each — one line each. A code without both evidence
slots filled is **missing data, not a zero**. For a pole present by withholding (the catastrophe heard
but never shown), the evidence slot must name the *positive trace* of the absence: the sound, the gaze,
the laid-out object. "It is implied" is not evidence.

**Require an alternative reading.** For the strongest code, the coder writes two to four sentences giving
a second defensible reading, naming what it would change about the other round 2 codes. This is the main
guard against treating an image as a one-to-one code for an event. A unit with no plausible alternative
is either trivially coded or over-read.

## The variable that usually needs inventing

Interpretive projects often describe a distinction in prose without making it a coded dimension —
"made visible, displaced into fantasy, or stored in empty space and abandoned objects" is a variable
nobody wrote down. Look for it: it is usually the variable the central claim actually lives in. Give it
explicit levels (for that example: `body` / `object` / `landscape` / `absence`) and a priority test for
when several apply — *remove this element; does the pattern survive?* The element whose removal destroys
it is the one to code.

## The exclusion list

Write down what you are deliberately not coding, and why. It is what stops these reappearing during
writing:

| Not coded | Why |
|---|---|
| severity or intensity ratings | attributes a state to a text |
| authorial intention | not recoverable from the image; production notes are context, not evidence of intent |
| audience response or likely effect | out of scope for a representation study |
| national or cultural character | no inference from images to a population |
| symbol-to-event mapping | the link must be argued from form plus context, never assumed from resemblance |

## Training before the main pass

1. Coder 2 reads the codebook and the design's setup sections — **not the hypotheses**.
2. Both code a small training set drawn from outside the analysis sample; the analyst adjudicates a
   reference answer; discuss every disagreement.
3. Attach anchor images per ordinal level from that training set.
4. A second training block. Proceed only when ordinal disagreement is at most one level on nearly all
   units.

Recruit and train the second coder **before** the analyst codes the full corpus. A coder brought in
afterwards cannot be trained without contamination, and this is the step most often deferred and least
recoverable.

## Codebook versioning

If reliability triggers a revision, version-stamp the codebook and **recode everything** under the final
version. Partial recoding produces a dataset coded under two instruments. Adjudicated values inform the
revision; they do not replace the original codes in the analysis dataset, because post-discussion codes
would inflate the reliability just measured.
